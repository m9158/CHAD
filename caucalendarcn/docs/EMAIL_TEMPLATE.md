# 인증 메일 문구 (스팸함으로 덜 가게 하기)

Supabase 대시보드 → **Authentication → Emails(Email Templates) → Confirm signup** 에서
아래 내용으로 바꿉니다. (대시보드 메뉴 이름은 버전에 따라 조금 다를 수 있습니다.)

## 제목(Subject)

```
[CAU 中国留学生] 邮箱验证码 · 이메일 인증번호
```

## 본문(Message body)

```html
<p>你好 / 안녕하세요,</p>
<p>CAU 中国留学生 注册验证码 / 회원가입 인증번호입니다.</p>
<p style="font-size:24px;font-weight:bold;letter-spacing:4px;">{{ .Token }}</p>
<p>请在网页的验证码输入框中填写这个数字。<br>
   웹페이지의 인증번호 입력칸에 위 숫자를 입력해주세요.</p>
<p>如果不是你本人操作,请忽略这封邮件。<br>
   본인이 요청하지 않았다면 이 메일을 무시하세요.</p>
<p>— CAU 中国留学生 / caucalendarcn.co.kr</p>
```

## 지켜야 할 점 (스팸 필터에 덜 걸리는 요령)

- 본문에 **링크를 넣지 않습니다.** (숫자만 넣는 방식이라 링크가 필요 없음)
- 과장·광고성 표현(무료, 지금 바로, 클릭 등)과 느낌표를 쓰지 않습니다.
- 제목과 본문이 **같은 서비스 이름**을 일관되게 쓰도록 합니다.
- `{{ .Token }}` 가 반드시 들어가야 인증번호 방식이 동작합니다. 빠지면 가입이 안 됩니다.

## 이 문구만으로 부족할 때

개인 Gmail 로 보내는 신규 발신자는 문구와 무관하게 스팸 처리될 수 있습니다.
근본 해결은 **도메인 메일(예: noreply@caucalendarcn.co.kr)** + 도메인의 SPF/DKIM/DMARC 설정입니다.
그러려면 도메인 DNS 를 수정할 수 있는 사람(도메인 등록처 계정 보유자)이 필요합니다.
